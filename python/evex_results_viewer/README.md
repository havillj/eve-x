# EVE-X Results Viewer

## Python Modules

EVE-X Results Viewer requires Python 3 (version 3.8 or later), and the following nonstandard modules, in addition to those required by EVE-X:

- pdf2image
- dearpygui

The additional modules can be installed using pip or pip3. For example: 

'''
pip3 install pdf2image
'''

## Installing and running

Copy evex_results_viewer.py to the same directory as evex.py, as it uses the same config.py file.

To run EVE-X Results Viewer, run 
'''
python3 evex_results_viewer.py
'''
or
'''
python3 evex_results_viewer.py -root /path/to/data
'''
if you prefer to specify a root data directory (ROOT_DIR) other than the one specified in config.py.

## About

EVE-X Result Viewer is best used in full screen.

The program displays the results saved to the user's local machine in the RESULTS_DIR defined in config.py.

In EVE-X Results Viewer, there are tabs for the names specified in the results 
directory (default to specimens and viruses). The user can adjust the slider on the right of the 
box containing the specimens and viruses tabs to view or hide the name of the tabs that can extend 
behind the boundaries of the menu. 

In the specimens tab, there is a tab for each specimen, and for each specimen, there is a diagram 
and sequences tab. In the diagrams for the specimen tab, there is a tab for each virus family EVE-X 
identified, and in each virus family, the user can click a button to view any of the contig images that
EVE-X generated. In the sequences tab, the user can click a button to display the hits aligned and 
unaligned.  You can copy any sequence to the clipboard by clicking on the name of the hit  
or the sequence itself. In the aligned hits, the hits are aligned and color coded with each 
host and reference pair EVE-X found. In both aligned and unaligned files, the user can drag the 
scrollbar to view the entire sequence.

In the viruses tab, there is a tab for diagrams and sequences. In the diagrams tab, there is a tab for 
each virus family, and in each virus family, there is a button to display each pdf file under the 
the virus family tab. In the sequences tab, it is also split into virus families, and under each 
virus family tab, it has buttons for each of the fasta files generated by EVE-X. Similar to the files 
labeled aligned and unaligned in the specimens tab, the sequences would display appropriately depending
on whether it has aligned or unaligned in the name of the file. Also, like the aligned and unaligned files
under specimens, the user can click on the name or the sequence to copy the sequence to their clipboard.
The user can also click on zoom out to view a simplified version of the sequences where each sequence is
represented by a line and the alignment of bases are represented by rectangles overlapping the lines.

Also under each virus family tab, there is a clustered tab that has fasta and text files EVE-X generates.
The fasta files are displayed with the reference sequence at the top, and each cluster group is organized 
numerically depending on their cluster number. The user also has the option to change the cluster number, 
and the user can click on save changes whenever they change the cluster number for a 
specific sequence. Save changes also writes back to the file, so the user can keep the changes made 
even after they exit EVE-X Results Viewer. The user can also view the sequences in a "zoom out" mode, where
each sequence is simplified to be a line, and the presence of bases are represented as a rectangle 
that overlaps with the line. The user can click on each sequence to edit the cluster number the sequence 
belongs to, and the user can click on save changes to update the order. This will bring the user back to
the original window with the updated sequences order. 

Within the clustered tab, there is a tab for each virus. In each virus tab, the fasta files are displayed how
EVE-X generated them, and the insertpositions pdf and txt files can also be displayed by clicking on the 
respective tabs.
